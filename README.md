# Sistema de Gestión de Biblioteca - POO

Proyecto integrador de Programación Orientada a Objetos (Recuperación).

## Tecnologías utilizadas
- Lenguaje: Java
- Paradigma: Programación Orientada a Objetos (Encapsulamiento, Herencia y Polimorfismo)

## Clases del sistema
- `Publicacion` (clase abstracta - superclase)
- `Libro` y `Revista` (subclases con herencia y polimorfismo)
- `Usuario`
- `Biblioteca` (gestión de publicaciones y préstamos)

## Cómo ejecutar (en consola)
```bash
javac *.java
java Main
